# Objetivo:
Desenvolver um compilador para uma linguagem de programação acessível voltada ao ensino de programação para pessoas com TEA.

# Descrição:
Esse é um projeto acadêmico voltado para o desenvolvimento de compiladores para as matérias de Linguagens Formais e Autômatos e Complexidade de Algoritmos.
Mesmo que alunos diagnosticados com algum nível de Transtorno do Espectro Austista (TEA) absorverem conceitos de maneiras diferentes, podemos traçar alguns padrões onde encontram dificuldades. Como por exemplo, na concentração e no entendimento de conceitos abstratos.
Por isso, esse projeto busca elaborar uma Linguagem de Programação acessível para alunos com TEA (principalmente crianças). Para que seja possível criar e executar programas utilizando essa linguagem, também será desenvolvido um compilador específico, TEApiler.
Em conjunto com esse projeto prático, também está sendo escrito um artigo para fundamentar os conceitos aplicados de Complexidade de Algoritmos. Realizando uma análise assintótica nos algoritmos e estruturas utilizadas na fase de Scanner e Parser do compilador.
